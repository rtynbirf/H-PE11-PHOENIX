# ФЕНИКС-11 // PHOENIX-11

![PHOENIX-11](brand/PHOENIX-11_wallpaper.png)

**Встаёт из пепла. Поднимает другие.**

PHOENIX-11 (внутренний каркас H-PE11) — оригинальная многофункциональная сборка
WinPE 11 («БОМБА»), собранная без ADK/DISM: **wimlib 1.14.4 + pycdlib**, на базе
официального `boot.wim` Microsoft Windows 11 26H2 x64 ru-RU (26300.9457).
Записи BIOS+UEFI — подлинные файлы MS (`etfsboot.com` + `efisys.bin`).

## Закон проекта
- **ЧЕЛОВЕК = СИСТЕМА = ЦЕЛОЕ** (больше суммы частей)
- **СОВЕРШЕНСТВУ НЕТ ПРЕДЕЛА**
- **EV.1**: недоступно = `[--]` — честность формулировок важнее красивых отчётов
- **Law 4**: все артефакты с SHA256

## Политика тачпада (решение Хозяина)
**СТАНДАРТНЫЙ in-box Microsoft** (`hidi2c` + `iaLPSS2i_I2C` уже в базе).
Вендорные паки Synaptics/ELAN/ALPS — **запрещены, 0 байт на борту**:
весят духуя, толку от их настроек нулевые. Тачпад = обычная мышь.
Подробнее: [TOUCHPAD-POLICY.md](TOUCHPAD-POLICY.md)

## TweakPack (v1.3+, октябрь 2026): перенос TweakHub + своё

Полный перенос каталога **PrimeBuild-pc/TweakHub v1.5.0** (аудит TH-AUDIT-1) в
paste-and-run пакет в стиле бомб-скриптов + эмерджентное сверху:
детекции по железу (диск/GPU/адаптеры), сервисный уровень телеметрии,
персистентный бэкап (JSON-журнал + целые ключи .reg + .pow), режимы
Report/Apply/Restore, метрики ЭВ.1. Тренды сверены: WinUtil 2026
(Security-режим WU 365д/4д), Atlas v0.5.0 (SysMain НЕ трогаем по умолчанию).

```

```
