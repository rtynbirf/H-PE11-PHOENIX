PHX-HUB v1.1 - единый центр управления системой
Проект H-PE11 // PHOENIX
====================================================

ЧТО ЭТО
Механизм в духе TweakHub, собранный на нативном PowerShell 5.1 + WPF:
ноль внешних зависимостей, ничего не устанавливает, один файл
(120 КБ против 70 МБ рантайма .NET у оригинала).
Твики реестра, профили одним кликом, скор безопасности, устройства и
MSI-режим, схемы питания, DNS, чистка мусора из Store, службы,
журнал с полным откатом любых изменений.

НОВОЕ В v1.1 - ПРОФИЛЬНЫЙ ДВИЖОК (TweakHub-стиль, наш)
- ИМПОРТ И ПРИМЕНИТЬ: JSON-профиль применяется ЦЕЛИКОМ одной кнопкой
  (раньше импорт только проставлял галочки).
- VERIFY-ПРОХОД: после применения каждое значение перечитывается
  из системы и сверяется; итог - "N из M совпало" + список расхождений.
- КАТАЛОГ ВНЕШНИХ ПРОФИЛЕЙ: %ProgramData%\PHX-HUB\profiles - положи
  туда JSON-файлы, они появятся карточками рядом со встроенными
  (кнопки "Обновить каталог" и "Папка профилей").
- СЛУЖБЫ В ПРОФИЛЯХ: формат v1.1 поддерживает services:[{name,start}],
  принимаются только службы из безопасного списка и только
  Automatic/Manual/Disabled. Старые профили v1.0 читаются как есть.
- Формат профиля v1.1: { ver, name, host, os, date,
  tweaks[], appx[], services[] } - обратная совместимость полная.
- Профиль PHX-HUB-PROFILE-OPTIMAL.json (26 твиков + 17 приложений)
  приложен отдельно: ИМПОРТ И ПРИМЕНИТЬ - и станция настроена.

КАК ЗАПУСТИТЬ
1. Двойной клик по PHX-HUB-LAUNCH.bat
2. Подтвердить UAC (иначе будет режим "только просмотр")
Всё. Бат и PS1 должны лежать в одной папке.

ПРАВИЛА БЕЗОПАСНОСТИ
- Перед каждым изменением реестра ключ автоматически экспортируется
  в %ProgramData%\PHX-HUB\backup\<группа>\<ключ>.reg
- Каждая операция пишется в журнал %ProgramData%\PHX-HUB\journal.jsonl
- Откат одной группы или всего сразу - раздел ЖУРНАЛ И ОТКАТ
- Массовые операции (в т.ч. профили) предлагают точку восстановления
- Удаление приложений - только для текущего пользователя,
  возврат - из Microsoft Store
- Службы - только смена типа запуска, прежний тип в журнале
- Службы из профиля - только из безопасного списка v1.1
